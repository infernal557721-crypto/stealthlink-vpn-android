# StealthLink VPN (Android)

**StealthLink** is a next-generation VPN client built for speed and privacy.

## Features
- **V2Ray Core:** Modern protocols (VLESS/VMESS) support.
- **Split Tunneling:** Select which apps use VPN.
- **Material You:** Beautiful Jetpack Compose UI.

## How to Build (Automatic)
This repository uses **GitHub Actions**.
1. Upload these files to GitHub.
2. Go to the **Actions** tab.
3. Wait for the green checkmark.
4. Click on the workflow run -> **Artifacts** -> `app-debug`.
